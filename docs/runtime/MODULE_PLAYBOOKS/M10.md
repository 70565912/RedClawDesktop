# M10 Playbook - Diagnostics, Metrics, and Logging

## Scope
Structured diagnostics, telemetry counters, support bundle export with redaction.

## Dependencies
- All modules emit metrics/logs through M10 contracts.

## Stage Tasks
- foundation:
  - M10-T01
- implementation:
  - M10-T02
- integration:
  - M10-T03
- hardening:
  - log volume and performance impact tuning.

## Tests (mandatory)
- Redaction unit tests.
- Support bundle generation integration tests.
- Required-field coverage tests.

## Done Criteria
- Debug data is sufficient for troubleshooting without secret leakage.
- Mandatory tests pass.

## First Action
Pick `M10-T01` unless already done.
