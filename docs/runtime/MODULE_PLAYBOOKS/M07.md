# M07 Playbook - Unattended Service and Boot-Time Host

## Scope
Windows service install/start/stop lifecycle, boot-time host availability, pre-login path and user-session handoff.
Includes privileged full-control verification and remote UAC confirmation broker path.

## Dependencies
- M01/M02/M03 for connection and security path.
- `docs/architecture/unattended-boot-access-design.md` is mandatory reading.
- `docs/architecture/m07-prelogin-user-session-handoff-design.md` is mandatory reading for `M07-T03`.
- `docs/architecture/privileged-full-control-and-uac-design.md` is mandatory reading for `M07-T04`.
- `docs/architecture/m07-privileged-broker-interface-and-state-machine.md` is mandatory implementation reference for `M07-T04`.

## Stage Tasks
- foundation:
  - M07-T01
- implementation:
  - M07-T02
- integration:
  - M07-T03
  - M07-T04
- hardening:
  - reboot and upgrade reliability matrix.

## Tests (mandatory)
- Service install/start/stop/uninstall automation.
- Reboot pre-login readiness check.
- Pre-login to post-login handoff test.
- Authorized remote UAC confirmation path under full-control policy.
- Unauthorized UAC input deny path with audit validation.

## Done Criteria
- Host reachable after boot without interactive login (policy enabled).
- Mandatory tests pass with logs and audit traces.

## First Action
Pick `M07-T04` target-environment evidence closure unless already done.
