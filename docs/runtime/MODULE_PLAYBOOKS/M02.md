# M02 Playbook - Offline Signaling Exchange

## Scope
Encrypted offer/answer blob generation, QR text transport format, versioning.

## Dependencies
- M03 for key material and handshake constraints.

## Stage Tasks
- foundation:
  - M02-T01
- implementation:
  - M02-T02
  - M02-T03
- integration:
  - Offline copy/paste two-end bootstrap with M01.
- hardening:
  - Blob backward compatibility checks and corruption tolerance.

## Tests (mandatory)
- Blob schema encode/decode unit tests.
- Wrong passphrase negative tests.
- Corrupted payload parsing tests.

## Done Criteria
- Signal path works without signaling server.
- Mandatory tests pass.
- Documentation and boards updated.

## First Action
Pick `M02-T01` unless already done.
