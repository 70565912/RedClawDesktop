## Dependencies

## Stage Tasks

  - M05-T01
- implementation:
  - M05-T02

- Resolution switch integration tests.
- Render continuity checks.

## Done Criteria
- Render path remains responsive during stream changes.
- Mandatory tests pass and metrics logged.
