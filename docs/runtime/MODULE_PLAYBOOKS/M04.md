Includes DirectX game window compatibility and backend fallback telemetry.

- M10 metrics for fps/latency counters.
- `docs/architecture/directx-capture-compatibility-design.md` is mandatory reading for `M04-T04`.

## Done Criteria
- Stable capture+encode under baseline load.
- Mandatory tests pass.
