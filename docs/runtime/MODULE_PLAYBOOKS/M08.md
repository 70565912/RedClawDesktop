# M08 Playbook - Clipboard and File Transfer

## Scope
Clipboard sync and resumable file transfer over reliable secure channels.

## Dependencies
- M03 secure channel primitives.
- M09 session-level flow control.

## Stage Tasks
- foundation:
  - M08-T01
- implementation:
  - M08-T02
- integration:
  - M08-T03
- hardening:
  - large-file interruption/retry stress.

## Tests (mandatory)
- Clipboard protocol unit tests.
- Chunk retransmission and resume token tests.
- End-to-end checksum verification.

## Done Criteria
- Text clipboard and file resume behavior validated.
- Mandatory tests pass.

## First Action
Pick `M08-T01` unless already done.
