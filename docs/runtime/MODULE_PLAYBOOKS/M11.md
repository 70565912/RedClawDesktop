# M11 Playbook - Mobile/Tablet Portable Companion

## Scope
Portable Android client for phone/tablet to support fragmented remote development tasks: session status, guarded command presets, and artifact/log review.
No controlled keyboard/mouse input in current scope.

## Dependencies
- Reuses M01/M02/M03/M09 transport/session/security primitives.
- Uses M10 diagnostics outputs for portable dashboard and quick triage.

## Stage Tasks
- foundation:
  - M11-T01
- implementation:
  - M11-T02
- integration:
  - M11-T03
- hardening:
  - mobile policy tuning, notification throttling, offline resume behavior.

## Platform Boundary (Current)
- Implement now: Android phone/tablet companion.
- Plan only: mac portable companion variant and generic web mini access client.

## Tests (mandatory)
- Command policy deny/allow unit tests.
- Multi-device bind and session resume integration tests.
- High-risk action confirmation and biometric gate tests.

## Done Criteria
- Developers can complete short remote maintenance loops from phone/tablet with explicit safety boundaries.
- Mandatory tests pass and risky actions remain policy-gated.

## First Action
Pick `M11-T01` unless already done.
