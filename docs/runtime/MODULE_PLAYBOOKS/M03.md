# M03 Playbook - Secure Session and Identity

## Scope
Bootstrap authentication, replay protection, ephemeral key agreement, peer fingerprint verification.

## Dependencies
- Shared by M01/M02/M09.

## Stage Tasks
- foundation:
  - M03-T01
- implementation:
  - M03-T02
  - M03-T03
- integration:
  - Handshake success/failure flow with M01 and M02.
- hardening:
  - Key rotation and sensitive-memory lifecycle checks.

## Tests (mandatory)
- Replay rejection unit tests.
- MITM/tamper negative integration tests.
- Key derivation vector tests.

## Done Criteria
- Unauthenticated peers cannot establish session.
- Mandatory tests pass and logs redact secrets.

## First Action
Pick `M03-T01` unless already done.
