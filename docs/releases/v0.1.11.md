# RedClawDesktop v0.1.11

Release type: Windows x64 Developer Preview / GitHub Pre-release.

This release transfers clipboard contents when they are pasted and repairs input pauses caused by bursts of queued input or long file transfers.

## Changes since v0.1.10

- Both endpoints announce copy/cut metadata without automatically transferring contents. Ctrl+V, Shift+Insert and native application paste requests share the same on-demand transaction. Text, HTML/RTF and images are retrieved when pasted; files and folders require a confirmation before content transfer and show cancellable progress.
- Native clipboard retrieval runs on a dedicated Windows OLE thread. Format queries and opening a paste menu do not download files. Transfer and verification release the input pause before the target application's own paste/conflict handling, while the current batch remains reserved.
- File cuts complete through the original source application's native move feedback only after verified, unambiguous completion. Partial results, changed sources and missing completion receipts preserve source data or report an unknown result; RedClaw does not delete source paths itself.
- Coalesce eligible consecutive mouse-motion and synchronization events inside the bounded Host input inbox, preserve key/button/Stop ordering, and avoid accumulating redundant input acknowledgements during transfers. Preserve the original control-pause cause when capture recovers.
- Retain playback output-window rebinding and canvas-layout repairs, validated maintenance startup authorization, and executable-bound incremental Debug build receipts. Existing connected-Host update-restart protection remains included.
- Make legacy clipboard UI tests independent of the interactive clipboard while covering capability-5 shortcuts and safe rejection of unsupported legacy file pastes.

## Compatibility and upgrade

Native on-demand file paste and cross-machine moves require **clipboard capability 5 on both endpoints**. Supported authenticated older releases still connect using common capabilities, retaining explicit text paste and manual file transfer. Legacy automatic clipboard return is no longer triggered. Upgrade the Host and Controller to use native file paste; identical versions, commits or binary hashes are not connection requirements. Passwordless v0.1.3 and earlier remain rejected.

For a serving Host, prepare the complete candidate and independent recovery worker before changing the running program. The worker retains the old directory and restores it if startup or required Host publication fails.

## Validation and limits

Serial Release builds pass, and all **127 automatic CTest suites** pass with zero failures or skips, including 731 GTest cases. The complete 342-file portable package passes checksum/content checks and extracted command startup. Isolated pairings with the official v0.1.10 package meet real-capture, codec and GUI-presentation checks in both directions. The old-Host/new-Controller case uses online DHT and recovers after replacing the test Host with v0.1.11; the reverse case uses diagnostic file signaling. Both fixture aggregate results remain failed solely because their playback screenshots are rejected as obscured; no Release screenshot proof is claimed. Evidence and scope are recorded in the [development log](https://github.com/70565912/RedClawDesktop/blob/main/docs/logs/DEVLOG.md).

Earlier Debug qualification covers bidirectional clipboard protocol/native-object fixtures, cancellation and stale-message handling, 13 GiB metadata without eager content reads, input gates and source-retention cases. The physical peer Host upgrade and automatic reconnect restore real video and capability 5. One operator-confirmed remote-to-local native copy transfers and verifies all 975,685,037 bytes; the target file opens normally and remote input remains active afterward.

That physical copy does not requalify reverse-direction native copy or real application cut/move deletion. No long continuity/stress test, GUI-hang root-cause fix, priority change or terminal-text paste change is included. The portable package remains unsigned and does not claim every GPU/NAT/TURN combination.

## Download

```powershell
Get-FileHash .\RedClawDesktop-windows-x64-v0.1.11.zip -Algorithm SHA256
```
