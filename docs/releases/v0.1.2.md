# RedClawDesktop v0.1.2

Release type: Windows x64 Developer Preview / GitHub Pre-release.

Historical candidate, not a published release. On 2026-09-20 the operator selected the complete current mainline as v0.1.3, incorporating this capture/recovery work and the remote workspace. Use the [v0.1.3 notes and package](v0.1.3.md); the candidate details below preserve their original scope and evidence.

## Changes since v0.1.1

- Preserve capture failure stage, category and raw HRESULT, with detailed desktop/session/display evidence kept in local files.
- Rebuild DDA after access/device loss and use permission-gated DDA → WGC → GDI fallback. Pause after all eligible backends fail; retry on a desktop/display change or an explicit user action.
- Discard old capture generations, request a fresh keyframe, pause/release Host input and wait for fresh presentation before recovery. New peers show capture pause state; control resumes only after a new user request.
- Include the Host's real cursor consistently through DDA shape composition, WGC cursor capture and GDI hotspot-aware composition. The Controller's system cursor remains unchanged.
- Extend Control v1 with optional versioned capture status and retry capability while preserving legacy peer behavior.
- Add an independent complete-directory upgrade path with exact GUI/runtime ownership checks, current-user handoff, full bundle validation, preserved launch arguments and startup rollback.
- Preserve the tested Controller source-address selection when a selected physical adapter has multiple IPv4 addresses.
- Include the protocol codec tool in the portable runtime package and support independent Host/Controller binaries and ports in the local compatibility harness.

## Install and upgrade

Verify `RedClawDesktop-windows-x64-v0.1.2.zip` against `SHA256SUMS.txt`, extract into a new directory and launch `redclaw_desktop.exe`. Supported peer versions use their common capabilities. A new Controller cannot supply cursor corrections that require a new Host.

The package remains portable and unsigned. The service MSI is not part of this Developer Preview. Development machines may use Debug bundles built from the release commit; those are distinct from the public Release ZIP.

For Agent-assisted maintenance, follow the [independent upgrade procedure](../testing/runtime-directory-upgrade.md). Confirm handoff before stopping the current Host/Agent; verify real frame progression separately from GUI startup and network connection.
