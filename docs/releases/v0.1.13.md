# RedClawDesktop v0.1.13

Windows x64 Developer Preview

## Changes since v0.1.12

- **Video.** Automatic codec selection prefers HEVC when the Host has hardware HEVC encoding and the Controller can decode HEVC in hardware on its display adapter. Other combinations use H.264. The Video codec setting can force H.264. The Controller pauses decoding and presentation when its D3D11 playback window is hidden, minimized, fully covered or the display is off. Playback requests a fresh keyframe when it becomes visible again.
- **Display switching.** An ordinary display switch keeps an active control session while the Host waits for the new capture. Input resumes after the Controller confirms the new geometry and presents a frame. With control off, Start Control refreshes as soon as those conditions are met. A failed capture, expired lease or disconnected session still pauses input.
- **Input recovery.** The Host's ordinary-desktop recovery prompt stays responsive. It offers a way to dismiss the prompt or send a normal Windows close request to the window that triggered it. Both sides record the first reason an active control session pauses.
- **Clipboard and reconnect.** The File/Clipboard panel keeps its open or closed state when automatic reconnect interrupts a paste. The Connection overlay shows reconnect progress. A paste failure during an active connection appears over the desktop without taking keyboard focus.
- **Developer builds.** The Windows build script selects the Visual Studio environment that matches the compiler named by the local CMake preset.

## Compatibility and upgrade

Authenticated peers continue to use their common capabilities. Older peers without HEVC negotiation use H.264. Native on-demand paste continues to require clipboard capability 5 on both endpoints.

Extract the complete portable directory into a fresh location. To replace an active Host, use the independent maintenance workflow with a complete candidate and rollback directory.

The separate report of control ending after idle remains under investigation. The input lease stays at three seconds. The portable package is unsigned.
