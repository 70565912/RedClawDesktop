# RedClawDesktop v0.1.0

Release type: Windows x64 Developer Preview / GitHub Pre-release.

## Highlights

- Host and Controller desktop GUI connected by device code.
- Public-DHT online rendezvous and ICE/STUN/TURN negotiation.
- Configurable fixed ICE UDP port, default 55000, with early port reservation and ICE-targeted UPnP mapping.
- Real Windows desktop capture, H.264/HEVC codec path, D3D11 decoding/presentation, and latest-frame queue semantics.
- Explicitly authorized keyboard and mouse control with fail-closed lease and lifecycle handling.
- Control, Media, and optional remote Agent DataChannels with Codex/Cursor provider integration.
- Visible Agent account login progress, command output, failure details, cancellation, and retry guidance in the Host settings dialog.
- Bounded, redacted diagnostics and local evidence export.

## Install

1. Download `RedClawDesktop-windows-x64-v0.1.0.zip` and `SHA256SUMS.txt`.
2. Compare the archive hash with `SHA256SUMS.txt`.
3. Extract into a new directory and launch `redclaw_desktop.exe`.
4. Use the same release on both Host and Controller.

The package is portable, unsigned, and does not install the Windows service. Windows SmartScreen may display a warning.

## Network setup

The product default is UDP 55000 for ICE. UPnP maps this ICE port when enabled. For manual router configuration, map UDP 55000 externally to UDP 55000 on the RedClaw machine, or use the alternative ICE UDP port configured in the GUI. The DHT listening port does not need a manual mapping.

Two different machines may both use 55000. Two RedClaw instances on the same machine need distinct ICE UDP ports; project tests use Host 55000 and Controller 55001.

## Verified scope

- Standard Debug and Release builds on Windows x64.
- Non-E2E unit tests plus focused fixed-port and UPnP regressions.
- Local dual-GUI real capture, transport, decode, presentation, remote input, and three-channel validation.
- Clean archive extraction and GUI startup from a fresh directory.

Hardware-sensitive performance metrics are reported against the product baseline but do not block this functional preview by themselves.

## Known limitations

- No signed MSI or unattended service installation is distributed in this release.
- Cross-site behavior still depends on NAT, CGNAT, firewall, ISP, and TURN availability; not every combination has been validated.
- Mobile clients and macOS/Linux desktop support are not included.
- Hardware codec and capture availability depends on the GPU, driver, Windows version, and active desktop session.
- Secure desktop and missing/expired authorization intentionally pause or reject remote input.

## Integrity

`RELEASE-MANIFEST.txt` inside the ZIP records the public Git commit, executable SHA256, archive file list, and build metadata. `SHA256SUMS.txt` published beside the ZIP records the final ZIP SHA256. The GitHub `main` commit, `v0.1.0` tag, and Release must refer to the same source commit.
