# Step Log Template

Use this template for every development step and append to `DEVLOG.md`.

```
### Step <N> - <Short title>
- Actions:
  - <what was implemented>
- Files:
  - `<path>`
- Tests:
  - `<test name>`: PASS/FAIL
- Issues:
  - <known issue or none>
- Risks:
  - <risk or none>
- Next:
  - <single next actionable step>
```
