# Security Policy

## Supported versions

`v0.1.0` is a Developer Preview. Security fixes are applied to the current `main` branch and the latest preview release.

## Reporting a vulnerability

Please use the repository's **Security** tab and select **Report a vulnerability** to open a private GitHub Security Advisory. Include the affected version, a minimal reproduction, impact, and any suggested mitigation.

Do not place credentials, session codes, ICE candidates, private addresses, local paths, runtime signaling, or unredacted diagnostic archives in a public Issue.

General bugs that do not contain sensitive information can be reported through [GitHub Issues](https://github.com/70565912/RedClawDesktop/issues).
